# Memorize Lab

Practice any text: pace guide, voice scoring, train modes, library, admin.

**Repo:** https://github.com/Sebrushton-ux/memorize-lab

## Deploy on Render (free, stable HTTPS)

1. Open https://dashboard.render.com/register — sign up with GitHub.
2. **New +** → **Web Service** → connect this repo.
3. Use:
   - Runtime: Python
   - Build command: `true`
   - Start command: `python backend/server.py`
   - Instance: Free
4. Deploy. Then open:
   `https://YOUR-SERVICE.onrender.com/memorize-lab.html`

Free services sleep after ~15 minutes idle. First visit after sleep can take ~1 minute.
